# RC-01 — Secure Telegram inbound (synthetic-only)

Branch: `ResidentChat/rc-01-secure-telegram-ingress`. Draft PR, not authorized for production.

## Endpoints
- `GET /health`: basic availability only; does not reveal configuration.
- `POST /telegram/webhook`: disabled by default; no outbound Telegram API, no AI, no data persistence.

## Runtime configuration (never commit secrets)

- `ResidentChat__Telegram__Enabled=true` (explicit opt-in)
- `ResidentChat__Telegram__WebhookSecret=<32-256 letters/digits/_/->` (runtime secret)
- `ResidentChat__Telegram__AllowedChatIds__0=<approved negative Telegram group ID>`

Enable only with owner authorization and customer privacy policy. Restrict ingress at TLS reverse proxy in production. The secret is verified using a timing-safe comparison; unconfigured values fail closed. Messages over 65,536 bytes, malformed JSON, unsupported content-types are rejected; unsupported update kinds and foreign groups are ignored. Only `message` updates for `group`/`supergroup` are considered.

**No message text is returned, logged, stored, forwarded or sent to any AI provider.** The application currently only acknowledges synthetic ingress metadata.

## Important limitation
`BoundedUpdateDeduplicator` is an in-memory, bounded replay window. It does not survive app restarts or work across replicas, and a sufficiently old update can be accepted again after eviction. Future work must use transactional persistence before any side-effecting actions or live deployment.

## Tests
Run:

```powershell
dotnet build tests/ResidentChat.SmokeTests/ResidentChat.SmokeTests.csproj -c Release
dotnet run --no-build --project tests/ResidentChat.SmokeTests/ResidentChat.SmokeTests.csproj -c Release
```

The synthetic smoke executable starts its own ephemeral **loopback HTTP** listener and checks disabled/invalid configuration, spoofed/missing header, malformed JSON, unsupported/private/foreign updates, duplicate update ID, 64 KiB size bound, invalid content type and no response-body echo. No live Telegram token is used.

## Do not deploy yet
Missing by design: authorized customer onboarding, durable dedup, admin authentication, ticket lifecycle, retention, privacy notice, egress firewall verification, full error-path security gate, and local-model evaluation.
